# top-op: 3D Topology Optimization Tool — Implementation Plan

## Context

Empty repo. Goal: a self-hosted tool where the user imports their own 3D model (STL/OBJ/3MF),
clicks faces or places primitives to define supports and loads, adds reference bodies as
keep-in (forced solid) / keep-out (forced void) regions, runs SIMP topology optimization, watches
density evolve live, and exports the result as STL for printing / further CAD.

Decisions already made with the user:
- **Stack**: Python core + FastAPI backend, Three.js (React + TypeScript + Vite) frontend.
- **Discretization**: voxel SIMP on a regular hex grid (top3d-style), not body-fitted tets.
- **Reference models**: keep-out (ρ=0) and keep-in (ρ=1) passive regions. No contact.
- **Selection**: face-pick in the 3D view (single, flat-face grow, brush) + box/sphere/cylinder primitives.

Target machine: M1 MacBook Pro 16 GB → design for ≤ ~250k active elements, warn above.
Units: whatever the user's model is in (mm/N/MPa assumed consistent). No conversion.

Agents build it; Fable (me) scaffolds conventions, briefs, reviews, merges, commits.
Model policy: **Opus** for anything numerical, geometric, or concurrency-sensitive. **Sonnet** for
scaffolding, UI panels, glue, tests, docs. Escalate to Opus on first failure.

## 2. Core numerics (`topop/core`) — Opus

### Grid & domain
- `Grid(origin, h, nx, ny, nz)`: cubic voxels of edge `h`. Resolution set by user as
  "elements along longest bbox axis" (default 60) → `h` derived; bbox padded by 1 voxel.
- `active: bool[nx,ny,nz]` = design-model occupancy ∪ keep-in masks − keep-out masks.
- `passive: int8[nx,ny,nz]`: 0 free, 1 forced solid (keep-in), −1 forced void (keep-out but
  still inside the design model: kept as elements at ρ=0 so loads can pass around them;
  keep-out outside the model is simply inactive).
- Elements outside `active` are **not assembled** (removed), not just set to E_min. Nodes are
  compressed to those touched by active elements. This matters: a bracket's bbox is mostly air.

### Element
- 8-node trilinear hex, 2×2×2 Gauss, isotropic E=1, ν → `KE(ν)` 24×24, scaled by `h` (3D: K ∝ h).
- Tests: symmetric, PSD, rank 18 (6 rigid modes), row sums 0, patch test (uniform strain exact).

### Assembly
- Precompute once per problem: `edof[nel,24]`, `iK, jK` (int32), and the COO→CSR index map
  (`np.unique` inverse) so each iteration is `data = bincount(inverse, weights=sK)`.
- `sK = KE.ravel()[None,:] * E_e[:,None]`, `E_e = Emin + ρ̃^p (E0 − Emin)`, Emin = 1e-9·E0.
- Memory guard: estimate bytes before allocating (576·nel·(4+4+8) + CSR); refuse above a
  configurable cap (default 6 GB) with a clear message telling the user to lower resolution.
- float32 option for sK/CSR (halves memory); default float64 in v1, benchmark both in Phase C.

### Linear solve
- Default: `pyamg.smoothed_aggregation_solver(K, B=rigid_body_modes)` as preconditioner for CG,
  tol 1e-6 relative, warm-start from previous iteration's `u`. Rebuild AMG hierarchy every
  iteration (cheap relative to solve) — Phase C may reuse it for N iterations.
- Fallback: `scipy.sparse.linalg.spsolve` for nel < 20k (tests, tiny runs).
- Supports applied by DOF elimination (slice K to free DOFs) — not penalty.

### Loads / supports
- `Load(nodes: int[], force: (fx,fy,fz) total)` → split equally over nodes.
- `Support(nodes, fix: (bool,bool,bool))`.
- Multiple load cases supported from the start: compliance = Σ_cases; each case is one solve.

### Filter & projection
- Density filter radius `rmin` (in voxels, default 1.5·… user-set, default 2.0). Implemented as
  FFT convolution (`scipy.signal.fftconvolve`) of the cone kernel over the full box grid, with a
  normalization field `Hs = conv(active)` so inactive voxels don't dilute the boundary.
- Chain rule for sensitivities uses the same conv (filter is symmetric).
- Heaviside projection (β continuation 1→64, η=0.5) behind a flag; off by default in v1.

### Optimizer
- OC with bisection on λ, move limit 0.2, standard `ρ·sqrt(−dc/(λ dv))` update, volume
  constraint on **active free** elements only (passives excluded from volfrac accounting).
- Stop: `max|Δρ| < tol (0.01)` or `max_iter (100)`. Optional penal continuation 1→3 over 20 its.
- `optimize(problem, params, callback)` where `callback(it, c, vol, change, rho) -> bool`
  (return False to cancel). The server hooks progress streaming here; the CLI prints.
- MMA is **not** in v1 (only one constraint). Interface leaves room for it.

### Voxelization (`voxelize.py`)
- `trimesh.load` → `mesh.voxelized(pitch=h)` on the common Grid → `.fill()` (hole fill) → mask.
  Non-watertight input: warn, still try; report `mesh.is_watertight` to the UI.
- Reference bodies: same routine with their 4×4 transform applied first; combine per mode.
- Returns occupancy mask + stats (n_active, n_nodes, est. memory, est. s/iteration from a lookup).

### Selection mapping (`selection.py`)
- Face selection: input = triangle ids of a mesh. Boundary nodes of the active grid (nodes of
  active elements that have at least one inactive/out-of-box neighbor) → `trimesh.proximity.
  closest_point` → triangle id; keep nodes whose closest triangle ∈ selection and distance ≤ h.
- Primitive selection: `Box/Sphere/Cylinder(transform)` → nodes inside (`surface_only` flag,
  default true so a box over a face doesn't grab interior nodes).
- Returns node ids + their coordinates so the UI can render the resolved markers before running.

### Export (`export.py`)
- `skimage.measure.marching_cubes(rho_padded, level=threshold)` → trimesh → optional Laplacian
  smoothing (`trimesh.smoothing.filter_laplacian`, few iterations) → STL bytes.
- VTI (density + passive mask) via a tiny hand-rolled writer (no VTK dep); NPZ raw dump.

### Benchmarks / regression (`benchmarks.py`, tests)
- 3D cantilever 60×20×4 (Liu & Tovar top3d), volfrac 0.3, penal 3, rmin 1.5: assert final
  compliance within ±3 % of the stored reference and the classic two-bar topology (checked via
  volume fraction in top/bottom thirds). Small 20×8×4 variant runs in CI in < 20 s.

## 4. Frontend (`web/`) — Sonnet (escalate picking/painting to Opus if it stalls)

- Vite + React 19 + TS + three 0.186 + zustand. No r3f: the viewport is a vanilla three class
  owning the canvas; React only renders panels and subscribes to the store.
- `Viewport.ts`: scene, OrbitControls, grid+axes, lights, resize, `loadMesh(buffer)` → BufferGeometry
  with per-face color attribute for selection highlight; `setMode('orbit'|'pick'|'paint'|'gizmo')`.
- `Picker.ts`: Raycaster → `faceIndex`; modifiers: click = single face, shift+click = flat-face
  grow (BFS over adjacency with normal angle ≤ 15°, slider), ctrl = remove. `SelectionPainter.ts`:
  brush radius in world units, drag to add faces whose centroid is within radius of hit point.
- `Primitives.ts`: Box/Sphere/Cylinder helpers + `TransformControls` (translate/rotate/scale),
  two-way bound to numeric fields in the panel.
- `Markers.ts`: resolved nodes as small points, load arrows at selection centroid, support
  glyphs; colors per load case.
- `DensityView.ts`: `InstancedMesh` cubes for ρ ≥ threshold (slider), viridis colormap, updated
  from binary WS frames; above 300k voxels fall back to `Points`. Final result: server STL
  loaded via STLLoader and shown with the design mesh ghosted.
- Panels: Import (file drop, watertight warning), Domain (resolution → calls voxelize, shows
  stats + memory/time estimate, warns red above thresholds), Loads/Supports (list, add from
  current selection, edit, resolve preview), Ref models (upload, mode, gizmo), Run (params,
  start/stop, live compliance/volume sparkline — inline canvas, no chart lib), Results
  (threshold, smoothing, export buttons, "reload project").
- Playwright e2e: `examples/bracket.stl` → pick top face → add load → shift-pick bottom face →
  add fixed support → add keep-out cylinder → resolution 24 → run 8 iterations → assert ≥8
  progress messages, density frames rendered, STL download > 0 bytes.

## 5. Server (`topop/server`) — Opus

- `jobs.py`: one `threading.Thread` per run (numpy/scipy release the GIL in the heavy parts);
  `cancel` sets an Event checked in the optimizer callback; progress pushed to an
  `asyncio.Queue` via `loop.call_soon_threadsafe`; WS consumer drains it. Density frames are
  quantized to uint8 and sent as binary WS messages. One run at a time per process (semaphore)
  — the Mac has one GPU-less CPU budget anyway.
- Uploads cached on disk under `~/.cache/topop/`; store is in-memory, projects persisted as
  JSON on every PUT so a server restart isn't a data loss.
- `app.py` mounts `server/static` (built frontend) at `/`; `topop serve --dev` proxies to Vite.
- `cli.py`: `topop serve`, `topop run case.json` (headless, prints progress, writes STL).

## 7a. Agent-drivable requirement (added by user mid-plan)

Claude must be able to run the whole workflow without the GUI: define boundaries, run, inspect.
- Every GUI action maps to a `ProjectIn` field; a case file is just that JSON with mesh `path`s.
- Query selections (`facets`, `normal`, `plane`, primitives) give an agent a way to name regions
  from the facet table / bbox alone. `GET /facets` + `preview.png` are the agent's "eyes".
- `topop mcp` wraps the API as MCP tools so a Claude session can drive it directly; `topop run`
  covers scripted/batch use. Both exercised in tests (`tests/test_cli.py`, `tests/test_mcp.py`).

Deferred or open:
- **AMFilter ignores the first active layer.** `core/filters.py` sets `xi[0] = x[0]` on layer 0 of the grid, which is the empty padding layer
  (`GridSpec.padding` defaults to 1), so every real layer sees an unsupported (zero) layer below. With `overhang` set the printed density
  collapses (the bracket at `--overhang +z` ends at volume 0.016 against volfrac 0.3 and "converges" with change 0 after 5 iterations).
  The base plate should be the first layer holding active cells. Until then the overhang tests only check plumbing.
- `FacetFaces` (response of the facet-faces endpoint) is defined in `routes_meshes.py`, not in `schemas.py`; move it there at the next contract revision.
- Stress is the relaxed voxel stress `rho^0.5 * sigma_vm(solid)`; sharp corners and the clamped face overshoot. No stress-based remeshing or smoothing.
- `trim=true` needs a closed, consistently oriented design mesh; otherwise it warns and returns the untrimmed surface. Trimming a ~200k-triangle surface takes under 5 s (`tests/test_export.py`).
- Several stress limits (per region or per load case) and local (non-aggregated) constraints are not supported.
